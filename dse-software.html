Portfolio · Software

At DSE I built the software that produced, checked and catalogued a teaching programme’s images, audio and video.

There are four parts: a teaching-image pipeline, a spoken-word audio pipeline with a blind listening test, a video-production workflow, and software that audits the files and reconciles them with the catalogue. The internship ran from June to September 2026.

DSE production system · images

Teaching-image pipeline

I built a pipeline that generated more than 7,000 photographic teaching images for an early-vocabulary programme. Written specifications cover words, phrases, sentences and recurring characters. Completed requests are skipped on later runs, and corrections to glossary entries or programme-wide prompt rules guide future generation.

Implementation detail

I chose background colours that separate each subject from its surroundings without changing its natural colour, because reduced contrast sensitivity is common in Down syndrome.

First production set delivered July 2026 · word images reviewed by a person

DSE production system · audio

Spoken-word audio pipeline

I generated text-to-speech audio for about 3,400 curriculum words, phrases and sentences, each in male and female voices across four English accents. I also built a blind A/B listening test, using a Bradley-Terry model and bootstrap intervals to compare voices. Most comparisons were ties, so the test resolved only one voice choice. The rest were selected by listening review after I adjusted each voice to the same measured pace.

Implementation detail

The scorer reports 90% intervals and flags voices that cannot be distinguished from the top-ranked one. A unit test caught a tie-handling error that would have awarded first place to whichever voice sorted first.

Sixteen voices selected across eight accents · four accents delivered

DSE production system · video

Video-generation workflow

I set up a workflow for short clips illustrating everyday verbs. Production instructions are generated from versioned specifications, with a check to prevent clips being catalogued against outdated briefs. API trials did not produce usable clips, so generation moved to the provider’s web interface.

Implementation detail

An audit I ran found that four of the eight validated prompts had drifted from their approved specifications. I then generated the instructions directly from the specifications, and added an automated check that the two match.

164 clips over 151 items, all reviewed · generation tools recorded in asset provenance

DSE production system · catalogue

Asset audit and catalogue integration

I wrote the pipeline that audits, repairs, uploads and reconciles more than 23,000 draft audio assets. Audio review combines measurements with listening checks. Each approved repair is recorded, so a later run keeps the corrected file rather than regenerating it.

Implementation detail

Uploads work from an approved inventory, and a content hash links each file to its catalogue record. The curriculum audio in four accents sits in the catalogue as drafts until a person approves it for publication.

Connection timeouts and session checks prevent stalled runs · file hashes link assets to catalogue records
